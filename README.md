# AWS Python Web Application Deployment Using Docker and AWS EC2

## Project Overview

This project demonstrates the deployment of a Python Flask web application using Docker and AWS.

The application is containerized using Docker, stored in Amazon ECR, and deployed on an Amazon EC2 Ubuntu instance. GitHub is used for source code management.

## Technologies Used

* Python & Flask
* HTML
* Docker
* Git & GitHub
* Amazon EC2
* Amazon ECR
* Amazon ECS/Fargate
* AWS Lambda
* Amazon API Gateway
* Ubuntu

## Architecture

GitHub → Docker → Amazon ECR → Amazon EC2 → Flask Web Application

The project also includes an AWS architecture using ECS/Fargate, Lambda, and API Gateway for understanding cloud-based application deployment.

## Objective

To build, containerize, and deploy a Python Flask web application using Docker and AWS cloud services.
